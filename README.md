# Фітнес-тренер

Кросплатформений фітнес-тренер (iOS, Android, веб) для набору маси, схуднення та підтримки форми.
Expo + TypeScript + Supabase. Інтерфейс українською, закладено i18n (англійська вже є).

План і етапи — [`docs/PLAN.md`](docs/PLAN.md). Правила коду — [`CLAUDE.md`](CLAUDE.md).

## Що вже працює (етап 1)

- Вхід через Supabase (пошта + пароль) або режим без акаунта (дані на пристрої).
- Онбординг: стать, вік, зріст, вага, активність, мета і темп з оцінкою кг на тиждень.
- Норма КБЖВ (Міффлін — Сан Жеор), запобіжники (мінімум калорій, швидкий темп, вік < 18, ІМТ < 18,5) і дисклеймер.
- Зважування з 7-денним трендом. Якщо тренд змістився на 1 кг і більше, норми перераховуються самі.
- Темна і світла теми, бокова навігація на ПК.
- SQL-схема всієї бази з RLS-політиками і приватними бакетами для фото.
- Юніт-тести всіх формул: КБЖВ, 1ПМ (Еплі / Бжицкі), прогресія і deload, норма води, тренд ваги.

## Етап 2: щоденник харчування і вода

- Щоденник по днях: сніданок, обід, вечеря, перекус. Кільця калорій і БЖВ, залишок на день.
- Пошук з автодоповненням, що враховує закінчення слів («вареників з картоплею» → «Вареники з картоплею»).
- Вбудована база: 183 українські страви і 79 базових продуктів зі стандартними порціями
  (тарілка, шт., ст. л.), працює офлайн.
- Open Food Facts (з українськими товарами) і USDA через Edge Function `food-search`, коли є акаунт.
- Порції: грами або штуки, ложки, тарілки. Редагування й видалення записів.
- Рецепти: збираєш страву з інгредієнтів, КБЖВ рахується сам, з урахуванням ваги готової страви.
- Свій продукт з етикетки з перевіркою, що калорії сходяться з БЖВ.
- Вода: +250 / +500 мл, свій об'єм, скасування, тренувальний день (+500 мл до норми).
- Офлайн-first: усе зберігається на пристрої, а після входу черга змін синхронізується з Supabase.

## Етап 3: тренування

- **Силова калібровка**: для 6 базових вправ вводиш «вага × повторення» будь-якого недавнього підходу.
  1ПМ рахується за Еплі (до 10 повторень) або Бжицкі (11–15), з точністю оцінки. Варіант «Не знаю»
  дає стартову оцінку за рівнем і масою тіла. Після кожного тренування 1ПМ оновлюється сам.
- **Каталог**: 90 вправ з технікою, типовими помилками, основними й допоміжними м'язами та місцем під відео.
  Пошук, фільтр за групою м'язів, «лише з мого залу», заміни.
- **Мій зал**: 39 типів обладнання й тренажерів, поширених в українських залах (Сміт, гакк, жим ногами 45°,
  гравітрон, пек-дек тощо), бренди (InterAtletika, Technogym, Matrix, Life Fitness, Hammer Strength, Panatta,
  Precor, Impulse), фото тренажера. Готові профілі залів — у тій самій таблиці `gyms`, тож пізніше можна
  додати профілі мереж.
- **Генератор програм**: мета (сила / маса / рельєф), досвід, 2–6 днів, 45–90 хв, обладнання залу.
  Спліти: все тіло, верх / низ, жими / тяги / ноги. Підходи × повторення, % від 1ПМ, відпочинок, RPE.
- **Прогресія**: усі повтори на верхній межі з RPE ≤ 8 → +2,5 кг (верх) / +5 кг (низ); нижче межі — повтор,
  двічі поспіль — −7,5 %. Розвантаження кожен 5-й тиждень (−40 % підходів).
- **Живе тренування**: підказка ваги з минулого разу, таймер відпочинку з вібрацією, RPE, заміна вправи
  (лише на сьогодні або в програмі назавжди), самопочуття й нотатка, тоннаж.
- **Календар**: місяць / тиждень, кольорові мітки груп м'язів, заплановане, виконане й пропущене;
  записати пропущене тренування заднім числом.
- Норма води сама додає +500 мл у тренувальний день.

## Запуск

Потрібні Node.js 20+ і npm.

```bash
npm install
cp .env.example .env        # можна не заповнювати: тоді працює режим без акаунта
npx expo start              # w — браузер, i — iOS-симулятор, a — Android, або QR для Expo Go
```

### Локальний Supabase (потрібен Docker)

```bash
npx supabase start          # виведе API URL і anon key — встав їх у .env
npx supabase db reset       # застосує міграції з supabase/migrations
```

Для хмарного проєкту: `npx supabase link --project-ref <ref>`, `npx supabase db push`,
потім seed (`psql "$DB_URL" -f supabase/seed.sql`) і `npx supabase functions deploy food-search`.
Ключі сторонніх API (Claude, USDA) задаються лише як секрети Edge Functions:
`npx supabase secrets set ANTHROPIC_API_KEY=...` — у клієнт вони не потрапляють ніколи.

## Перевірки

```bash
npm test                    # юніт-тести
npm run typecheck           # TypeScript strict
npm run lint                # ESLint (eslint-config-expo + prettier)
npm run format              # Prettier
npx expo export -p web      # збірка веб-версії в dist/
```

```
src/ui/           дизайн-система
src/i18n/         переклади uk / en
supabase/         міграції, конфіг, seed
docs/PLAN.md      план, схема БД, етапи
```
